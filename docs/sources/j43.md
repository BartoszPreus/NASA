# Sources of job J43 (issue #30): ranking key on narrow polar tiles

No external page was used. Everything below is code and data of this repository.

| What | Where |
|---|---|
| The fallback (before J43) | `pipeline/sites.py`, `best_window`: `if R < side or C < side: return float(P.sum()), (R // 2, C // 2)` |
| Window side | `pipeline/sites.py`, `BASE_REGION_KM = 15.0`, `window_side(cell_m)` = round(15000 / 1979) = 8 |
| The fix (default since J43) | `pipeline/sites.py`, `window_shape("clip", ...)` = (min(side, R), min(side, C)) and `best_window_rect`; option `--window-rule {clip,legacy,physical}` |
| The same fix in the rank-uncertainty copy | `validation/rank_uncertainty.py`, `_best_window` |
| Tile grids (rows, columns, cell size) | `data/earth/cells/*.parquet`, columns `tile`, `row`, `col`, `lat`, `lon`, `cell_m` |
| Measurement | `validation/window_rule.py` -> `data/validation/window_rule/window_rule.json` |
| Old rankings (legacy rule) | `data/validation/window_rule/ranking_legacy_window.csv`, `ranking_bare_strict_legacy_window.csv`; byte-identical (`cmp`) to `data/sites/ranking.csv` and `data/validation/landcover_sensitivity/ranking_bare_strict.csv` at commit `cbcaee4` |
| Alternative not chosen | `data/validation/window_rule/ranking_physical_window.csv` (`--window-rule physical`) |
| Test | `tests/test_window_rule.py` (synthetic 20 x 7 and 30 x 30 grids) |

Libraries: NumPy, SciPy (`scipy.ndimage.uniform_filter`), pandas. Written with SI assistance (Claude Code).
