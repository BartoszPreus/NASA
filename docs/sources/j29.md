# J29 — ALOS AW3D30 elevation comparison

JAXA AW3D30 v4.1 adds optical stereo heights to the comparison with Copernicus DEM GLO-30 (TanDEM-X radar) and
NASADEM_HGT v001 (SRTM radar). The [JSON report](../../data/validation/aw3d30_comparison.json) contains agreement
statistics and cell counts for all three pairs, overall and by tile. The [figure](../figures/aw3d30_comparison.png)
shows pooled Pearson correlations for the eight terrain features used in scoring.

## Method and coverage

Use `dem="aw3d30"` with `load_earth_tile` or `earth_cells_for_tile`. The loader reads the `DSM` and `MSK` assets of
the April 2024 release from the JAXA Earth API. It retains pixels with `MSK == 0` (original valid ALOS PRISM
observations), masks voids, and resamples the heights bilinearly to the same Copernicus grid as NASADEM. This
excludes gap fills from inputs such as SRTM and Copernicus before the existing terrain features are computed.

The six reference tiles cover Meteor Crater (`N35W112`), Harrat Khaybar (`N25E039`), Mauna Loa (`N19W156`),
the Atacama (`S25W070`), Niger (`N15E013`), and the Rub' al Khali (`N17E046`). Four controls cover a Saharan erg
(`N27E001`), the Wielkopolska lowlands (`N52E016`), the Tatras (`N49E020`), and the Alps (`N45E006`). All three
pairs use the same intersection of valid `(tile, row, col)` keys. The run found 15,761 shared cells and zero
difference between the stored cell-centre coordinates. Coverage ranged from 324 shared cells in `N52E016`
(1,903 valid in Copernicus) to 2,771 in `N25E039` (2,800 valid in Copernicus).

## Results

| Feature | Copernicus–NASADEM | Copernicus–AW3D30 | NASADEM–AW3D30 |
|---|---:|---:|---:|
| Slope, 240 m | 0.9991 | 0.9998 | 0.9992 |
| Slope, 570 m | 0.9997 | 0.9997 | 0.9996 |
| Roughness, 200 m | 0.9076 | 0.9929 | 0.9238 |
| Depression fraction | 0.6229 | 0.9647 | 0.6534 |
| Depression depth | 0.7606 | 0.9756 | 0.7805 |

The pooled Pearson correlations in the table show especially close agreement on slopes. Within `N52E016`, the
240 m slope correlations with AW3D30 were 0.943 for Copernicus and 0.937 for NASADEM. AW3D30 agreed more closely
with Copernicus on 200 m roughness and depression features on the shared sample. Their Spearman correlation for
depression fraction was 0.6770, so the closer Pearson agreement still allows meaningful differences in the
ordering of cells.

The shared sample reflects the cells retained in the committed radar tables and the availability of original
optical pixels. JAXA used Copernicus for anomaly detection in v4.1. The comparison measures terrain-feature
agreement on these cells. Surface heights include vegetation and structures, and AW3D30 and NASADEM use EGM96
where Copernicus uses EGM2008. The run evaluated terrain features without estimating absolute elevation accuracy
or the effect on the final analog ranking.

## Reproduce

`python validation/nasadem_vs_copdem.py --aw3d30-comparison` uses the committed Earth and NASADEM cell tables.
Run the downloads on the cloud runner. To prepare the smaller input files for the runner from the team checkout,
run from the repository root:

```python
from pathlib import Path

from pipeline import paths
from validation.nasadem_vs_copdem import reference_cells

output = Path(paths.RAW) / "j29"
output.mkdir(parents=True, exist_ok=True)
reference_cells(paths.earth_cell_tables()).to_parquet(output / "copdem.parquet", index=False)
nasadem = sorted(Path(paths.EARTH_CELLS_NASADEM).glob("*.parquet"))
reference_cells(nasadem).to_parquet(output / "nasadem.parquet", index=False)
```

Place the two files in `data/j29/` of the runner, copy the updated `pipeline/` and validation script, and dispatch
[`aw3d30-comparison.yml`](../../cloud/aw3d30-comparison.yml) from `.github/workflows/`. The published outputs came
from [GitHub Actions run 43656102530](https://github.com/witczakw/moon-scan-runner/actions/runs/43656102530)
using the team input tables at `2b7e9fa`.
