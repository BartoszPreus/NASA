Method notes
- Scoring is the tested one from `analysis/discovery_test.py` / `docs/TASKS.md` section 3; the regression on the
  pilot tiles agrees with `analysis/discovery_test_results.txt` (`dep_all`) within 0.5 percentage points.
- The reference is taken from `data/out/moon_reference.json` (J2) when it exists; otherwise built from the valid
  cells of the 160 x 160 km polar window and cached in `data/raw/j4_reference_polar_160km.json`. If J2's JSON has no
  per-group `d2` sample, `p_amp` / `p_dep` use the covariance sub-block with the chi-square law (marked `p_method`).
- `is_known` = site centroid inside the `radius_km` of any listed analog (default 50 km), not only the nearest one.
- Cells without WorldCover (`lc_source = "none"`, north of 82.75 N and Antarctica) can never be candidates in v1.
- Sites are found per tile; components touching a tile border are not merged across tiles in v1.
