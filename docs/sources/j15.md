# J15 sources: LRO instrument products for the lunar south-pole regions

Code: `pipeline/lunar_products.py` (registry + extractor), `cloud/lunar-products.yml` (GitHub Actions run).
Outputs: `data/moon/instruments/registry.json`, `*_regions.json`, PNG quicklooks in `data/moon/instruments/<instrument>/`.
Use: descriptive layer on the lunar region cards only; none of these values enter the similarity score.
Licence of all data below: NASA / PDS archive data, public domain in the U.S., free to use with citation
(NASA data policy; PDS archives are open without login). Sizes are HTTP Content-Length values from HEAD requests
made on 2026-11-14. Written with SI assistance (Claude Code).
