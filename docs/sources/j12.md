## 1. NASA POWER climatology API

- **Name**: NASA Prediction Of Worldwide Energy Resources (POWER), Climatology API, version v2.10.1 (as reported by the API response header), NASA Langley Research Center.
- **URLs**:
  - Endpoint: https://power.larc.nasa.gov/api/temporal/climatology/point
  - Docs: https://power.larc.nasa.gov/docs/ , https://power.larc.nasa.gov/docs/services/api/temporal/climatology/
  - Methodology (grid resolution): https://power.larc.nasa.gov/docs/methodology/
  - Parameter dictionary: https://power.larc.nasa.gov/api/system/manager/parameters/TS?community=AG (also TS_MAX, PRECTOTCORR, WS10M)
  - Referencing guide: https://power.larc.nasa.gov/docs/referencing/
- **What the docs and the API say**:
  - Parameters (from the parameter dictionary and the API response header): TS "Earth Skin Temperature", deg C, "The average temperature at the earth's surface."; TS_MAX / TS_MIN "The maximum hourly earth skin temperature in the period of interest." (and minimum), deg C; PRECTOTCORR "Precipitation Corrected", mm/day, "The average MERRA-2 bias corrected total precipitation at the surface of the earth."; WS10M "Wind Speed at 10 Meters", m/s.
  - Period: API header `"range": "25-year Meteorological and Solar Monthly & Annual Climatologies (January 2001 - December 2025)"` and message "The requested parameters are retrieved from a pre-computed climatological period (January 2001 - December 2025)". Sources listed in the header: `MERRA2`, `POWER` (not CERES for these parameters).
  - Grid: methodology page: "½° latitude by ⅝° longitude for the meteorological data sets" (1.0 x 1.0 deg for radiation data sets, not used here).
  - Rate limits: no rate limit is stated in the docs; the error table lists HTTP 429 "Too Many Requests". The climatology docs state "A maximum of 20 parameters can currently be requested in one submission for a single point." We use at most 4 parallel requests, retries with exponential back-off, and an on-disk cache.
  - UNVERIFIED: how the annual (ANN) value of TS_MAX / TS_MIN is computed. In the sample response ANN equals the maximum (minimum) monthly value, so we treat it as the extreme of the monthly climatology; the docs do not say.
- **Citation requested** (verbatim, "POWER's Reference"): "The data was obtained from National Aeronautics and Space Administration (NASA) Langley Research Center's Prediction Of Worldwide Energy Resources (POWER) project funded through the NASA Earth Science Division." The guide also asks to "include the service name, version number, and date accessed", and gives a Data Reference template: "The data was obtained from the POWER Project's Hourly 2.x.x version on YYYY/MM/DD." For us: "The data was obtained from the POWER Project's Climatology API v2.10.1 on 2026/11/14."
- **Other requests**: the Project "kindly requests that users of POWER data products send a reference, web link and/or a reprint ... to larc-power-project@mail.nasa.gov" and "requests notification if POWER data is transmitted to other researchers." (Human decision: whether to email them after the hackathon.)
- **Licence**: no separate licence on the referencing page; NASA Earth science data are released under NASA's open data policy (UNVERIFIED for POWER specifically).
- **Used for**: `data/out/site_nasa_context.csv` (annual mean, min, max skin temperature, precipitation, 10 m wind for the top sites of `data/out/ranking.csv`) and `data/out/site_nasa_context_summary.json` (range of annual mean skin temperature in kelvin).

## 2. NASA Worldview Snapshots API / NASA GIBS imagery

- **Name**: NASA Worldview Snapshots (https://wvs.earthdata.nasa.gov/), serving imagery from NASA Global Imagery Browse Services (GIBS).
- **URLs**:
  - Endpoint: https://wvs.earthdata.nasa.gov/api/v1/snapshot (parameters REQUEST=GetSnapshot, TIME, BBOX south,west,north,east, CRS=EPSG:4326, LAYERS, FORMAT, WIDTH, HEIGHT). The Snapshots web page documents the options (bounding box, date, layers, resolution) but no formal API reference and no limits on box or image size.
  - GIBS API docs and acknowledgement: https://nasa-gibs.github.io/gibs-api-docs/
  - Worldview source code: https://github.com/nasa-gibs/worldview (licence NASA-1.3; we do not use the code, only the service).
- **Layers used**: `MODIS_Terra_CorrectedReflectance_TrueColor` (Terra MODIS corrected reflectance, true colour); fallback `VIIRS_SNPP_CorrectedReflectance_TrueColor` (Suomi NPP VIIRS) when no MODIS date was cloud-free enough.
- **Citation requested** (verbatim, under "Data Use Guidance and Acknowledgements"): "NASA promotes full and open sharing of data. We ask that users who make use of GIBS in their clients or when referencing it in written or oral presentations to add the following acknowledgment: We acknowledge the use of imagery provided by services from NASA's Global Imagery Browse Services (GIBS), part of NASA's Earth Science Data and Information System (ESDIS)."
- **Worldview-specific citation**: the Snapshots page points to "Citation Guidelines" on the Earthdata Forum; https://www.earthdata.nasa.gov/data/tools/worldview returned HTTP 403 to our fetch, so no separate Worldview citation text was confirmed (UNVERIFIED). Using the GIBS acknowledgement above.
- **Used for**: `data/out/site_images/<site_id>.jpg`, a true-colour image of a box of 0.6 deg latitude by 0.6/cos(lat) deg longitude (capped at 3 deg) around each of the top 60 sites, 600 x 600 px; `data/out/site_images/index.csv` records bbox, date, layer and the near-white pixel share. Images are NASA satellite imagery, unmodified except for JPEG re-encoding if over 80 kB; no text, logo or watermark added.
