# J7 — Citations for the Earth–Moon Terrain Atlas

The app presents the supplied pipeline results. The [method](../METHOD.md), [source registry](../../data/sources.csv), and [data catalogue](../../data/README.md) link input products to the pipeline that used them. The atlas exports the complete registry with the original citation and use status.
