## Changed here: `pipeline/partner_context.py`
- A JAXA Earth API tile read that still fails after its retries, or a failed permafrost read (for example `ModuleNotFoundError: No module named 'numcodecs'`, seen on 15 Nov 02:18 in J25), now stops the stage with a non-zero exit code **before** any output is written. Finished reads stay in the cache, so a rerun only retries what failed.
- `--allow-missing jaxa` / `--allow-missing permafrost` writes the table anyway; the warning is printed and the summary JSON records `allow_missing`.
- Ground temperature is read from every Zarr chunk that holds a ranked or known site (`--ground-temp-chunks 0`, the new default; each chunk is about 10 MB). The old default of 4 chunks made the output depend on what earlier runs had cached: the committed table had 55 values, a rerun from the cache of 15 Nov gave 47. A limit can still be set; the number of sites it leaves out is printed and written as `permafrost.ground_temp_sites_not_read`.

## Tests
`tests/test_partner_context_failures.py`, offline (readers replaced by stubs): a failed JAXA read and a failed permafrost read each stop the stage and write nothing; `--allow-missing permafrost` writes empty columns and records it; ground temperature is read from all six chunks of a stub grid by default; a limit of two chunks reports four sites not read.

## Audit of the other stages (same pattern: an error is caught and the stage goes on)
Not changed by this job; each belongs to another job's files.

| File | Line (15 Nov) | What happens | Risk |
|---|---|---|---|
| `pipeline/score.py` | `score_all_regions`, `except Exception` | a lunar region whose reference fails is skipped with a printed line; its `p_all_<region>` columns are missing | `best_region` and per-region scores silently cover fewer regions |

| `pipeline/earth_scan.py`, `pipeline/lunar_products.py`, `pipeline/radarsat1.py`, `pipeline/tiles.py` | per tile / per product | the error is recorded per unit (status "error", `rejected` text) | by design for batch runs; the logs carry the errors |
