# Sources and notes for J32 (rank uncertainty per site, the scale of the similarity)

Written with SI assistance (Claude Code). No new external data: the job reuses committed tables.

## Data (all already in `data/sources.csv`)
- Copernicus DEM GLO-30 cells, `data/earth/cells/*.parquet`: https://spacedata.copernicus.eu/collections/copernicus-digital-elevation-model
- NASADEM + MODIS land cover cells, `data/earth/cells_nasadem/*.parquet`: https://doi.org/10.5067/MEaSUREs/NASADEM/NASADEM_HGT.001 , https://doi.org/10.5067/MODIS/MCD12Q1.061
- ESA WorldCover 2021 land cover (in the Copernicus cells): https://esa-worldcover.org/
- LOLA `LDEM_80S_20MPP_ADJ` lunar cells, `data/moon/cells.parquet` and `data/moon/reference.json`: https://pgda.gsfc.nasa.gov/products/90

## Method
- Nonparametric bootstrap (resampling the reference cells with replacement): B. Efron, "Bootstrap Methods: Another Look at the Jackknife", Annals of Statistics 7(1), 1979, https://doi.org/10.1214/aos/1176344552 . Not opened in this job; cited as the origin of the method (UNVERIFIED page content).
- Percentiles: `numpy.percentile`, linear method, https://numpy.org/doc/stable/reference/generated/numpy.percentile.html
- Connected sites: `scipy.ndimage.label` with 8-connectivity, the same call as `pipeline/sites.py`, https://docs.scipy.org/doc/scipy/reference/generated/scipy.ndimage.label.html

## Libraries
numpy (https://numpy.org/), pandas (https://pandas.pydata.org/), scipy (https://scipy.org/), matplotlib (https://matplotlib.org/).
