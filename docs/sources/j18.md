### 4. Sand-sea flag: a terrain rule that separates (implemented, not yet run in the full pipeline)
Distributions (quantiles 1/5/25/50/75/95/99%) of candidate cells under base_regions, from a scratch analysis using
the repo's `load_cells` / `score_cells`:
- `relief / r200` (cell P95-P5 elevation over 200 m roughness): lunar named-region cells 40 / **82** / 177 / 300 /
  446 / 745 / 954; sand-tile candidates 26 / 30 / 40 / 47 / 55 / **69** / 87; known-analog-tile candidates
  52 / 66 / 102 / 134 / 166 / 224 / 295.
- Ratios across roughness scales do NOT separate: `r1600/r200` median 14.7 (Moon) vs 16.8 (sand); `r800/r200` 5.4 vs
  6.0. The dune wavelength of these ergs is not below 1.6 km, so relief keeps growing up to r1600.
- `r200/s240` and `f_le5` also separate (sand P05 0.44 and 0.47; Moon P95 0.52 and 0.61) but flag more known-analog
  cells than `relief/r200`.

Rule adopted in `pipeline/sites.py` (`artefact_flags`, `artefact_threshold`): a cell is flagged when
`relief / r200` < the 5th percentile of the same ratio over the valid lunar cells of the target (81.84 for
base_regions; by construction 5.0% of those lunar cells, 12.2% of polar_160km cells). A site is flagged when >= 50%
of its cells are; columns `artefact_flag`, `artefact_share`, `artefact_reason`; option `--flagged last|keep`
(default: flagged sites ranked after all unflagged ones, never deleted). Numbers at threshold 81.84, base_regions
candidates: 18,655 of 63,618 (29.3%) flagged overall; sand-sea tiles 98.5% (N18E048 99.6%, N18E047 100%, N17E046
92.7%, N15E013 99.9%); other ergs also flagged (N19E052 97.3%, N32E008 100%, N17E012 100%, N29E007 88.5%, N25E012
82.0%, Namib S25E015 74.9%); Putorana (N68E093-N69E096) 0-2%; Atacama tiles 5-25%. Cost on known analogs: Mauna Loa
1.1%, Atacama core 11.5%, Devon N75W088 12.4%, **Devon N75W090 62.8%** (flat dissected plateau, would be flagged
at site level), Askja 24.0%, Harrat Khaybar 38.9%. By region: Sahara/Arabia 87.1%, southern Africa 64.5%, Arctic
17.5%, Americas 13.3%, Central Asia/Tibet 13.4%. Caveat: "relief" includes the regional tilt of the cell, so the
rule also catches any low-relief plain with metre-scale roughness, not only dunes.

### 5. Ranking keys (implemented, not yet evaluated on the full data)
`--rank-key best_window | capped_area | weighted_area` (default `best_window`). Per site: `weighted_area_km2`
(kept), `weighted_area_capped_km2` = min(weighted area, 225 km2), `best_window_km2` = similarity-weighted area of
the best 8 x 8-cell window (15.8 x 15.8 km at 1,979 m cells; side = round(15 km / cell size)) inside the site, with
its centre `window_lat`, `window_lon`. Tile summary gets `best_window_km2_max`, `n_candidate_flagged`, `target`.
ranking.csv gets `rank_key`, `target`, the three keys and the flag columns.

### 6. Fast enrichment (`validation/enrichment.py`, verified)
cKDTree on 3-D unit-sphere coordinates (two trees: bare, lunar-like bare), chord radius, vectorised over all
500 x n random centres with redraws. Checked against the old haversine counting on all 66 known rows: 0 mismatches.
Runs in 13.5 s on the full data (the old version did not finish). New options `--target`, `--out`, `--figure none`;
JSON gains `target`, `lunar_like_column`, `scored_target`. The target is read from the parquet metadata key
`j18_target` written by the new `pipeline.sites` (missing = polar_160km).

35 sites tested, 16 above the base rate, median enrichment 0.97; random circles median 0.48 (5-95%: 0.23-0.89), 12
sites above 1 (8-17); share of random runs with median >= ours 0.028. (On 78 tiles it was 21 of 31, 1.80.)
