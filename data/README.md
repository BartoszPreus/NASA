# data/: what is here, who made it, where it came from

Generated by `python -m pipeline.catalog` (do not edit by hand; edit the registries in `pipeline/catalog.py`).
Every location is defined once in `pipeline/paths.py`; scripts import it from there.
Full lists: [`catalog.csv`](catalog.csv) (one row per file) and [`sources.csv`](sources.csv) (one row per external source).

## Folders

```
data/
  README.md, catalog.csv, sources.csv   this catalogue (generated)
  reference/          hand-made or curated inputs: known analog sites, pilot tiles
  moon/               lunar targets: reference statistics, cells, footprints, hillshades
  moon/instruments/   one JSON (and small images) per LRO instrument, per lunar region
  earth/cells/        Earth cell tables with the terrain features (pilot, known-analog tiles, scan shards)
  earth/cells_nasadem/ the same cells recomputed from NASA inputs (NASADEM + MODIS land cover), for comparison
  earth/tiles/        scan plan and status, per-tile summary
  sites/              the product: candidate sites, ranking, compact scores, novelty, NASA context, images
  validation/         every validation result as JSON
  sample/             small fixtures for tests and for the app
  raw/                downloads and caches, one folder per source; git-ignored, safe to delete, rebuilt on demand
```

## How to rebuild everything (from the repo root, in this order)

1. `python -m pipeline.tiles --pilot / --select`: scan plan (needs network, cached in data/raw/tiles_cache/)
2. `python -m pipeline.earth_scan --tiles ... --shard i/N`: Earth cell tables (big scan runs on the cloud runner)
3. `python -m pipeline.moon_reference`: lunar reference, cells, footprints, hillshades
4. `python -m pipeline.sites`: scores, sites, ranking, tile summary, data/raw/earth_scored_full.parquet
5. `python -m pipeline.nasa_context --top 150 --images 60`: NASA POWER and Worldview per site (cached)
6. `python validation/pds_products.py --part all`: Diviner per region, PDS LOLA check
7. `python -m pipeline.lunar_products --fetch all / --extract all`: other LRO instruments (job J15)
8. `python validation/t1_reproduce.py`: reproduction of the NASA slope product
9. `python validation/enrichment.py`: enrichment test (needs data/raw/earth_scored_full.parquet)
10. `python validation/effectiveness.py all`: effectiveness tests (slow; caches in data/raw/validation/)
11. `python lidar/crater_profiles.py --part all`: crater close-up
12. `python validation/icesat2_profiles.py`: ICESat-2 check (job J14)
13. `python -m pipeline.fixtures --raw-dir data/raw`: fixtures in data/sample/
14. `python -m pipeline.catalog`: this catalogue

Tests: `python -m pytest tests -q`.

## data/raw/

Git-ignored. One folder per source; every script recreates what it needs, so the folder is safe to delete (rebuilding needs the network, about 0.3 MB/s at the venue). Folders present now:

- `raw/cells/`: per-tile Earth feature tables and scan logs
- `raw/cloud/`: artifacts from the cloud runner
- `raw/cloud_check/`: test artifacts of the cloud runner
- `raw/copdem30/`: Copernicus GLO-30 tiles
- `raw/icesat2/`: ICESat-2 subsets (job J14)
- `raw/j16_before/`: copies taken before the layout-v2 migration (regression check)
- `raw/j4_check/`: intermediate checks of job J4
- `raw/lidar/`: USGS 3DEP and GUGiK windows
- `raw/lro/`: other LRO instrument products (job J15)
- `raw/modis_igbp/`
- `raw/moon/`: LOLA DEM windows (NASA PGDA)
- `raw/nasa_context/`: NASA POWER and Worldview responses
- `raw/nasadem/`
